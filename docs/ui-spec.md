# 5. UI仕様

## 共通

- PC / スマホ両対応
- 色の意味を統一
  - 緑: 完了 / 順調
  - 青: 顧客確認
  - 紫: Wチェック
  - 黄: 作業中 / 注意
  - 赤: 遅延 / 催促
- 全画面共通で顧客検索
  - 顧客名
  - 店舗名
  - 顧客ID

## 左メニュー

日常:
- 担当者ダッシュボード
- 制作管理
- Wチェック待ち
- 全タスク
- 通知
- 催促

素材・投稿:
- 顧客向け素材フォーム
- 素材
- 投稿実績登録・履歴
- 投稿カレンダー
- 外注管理

顧客:
- 顧客一覧
- 顧客登録
- 顧客情報参照

管理:
- 管理ダッシュボード
- 担当者別進捗
- 社内タスク
- スタッフ管理

外部:
- 外注アップロードフォーム（専用URL）

## 担当者ダッシュボード

上:
- 今日締切
- Wチェック待ち
- 新着素材
- 素材待ち14日超
- 優先タスク
- 今やるべきこと

下:
担当顧客一覧（顧客登録順）

列:
- 顧客
- サービス
- 今月進捗
- 現在ステータス
- 最終素材
- 次にやること
- 顧客情報ボタン

ステータスは一覧から直接変更可。

## 顧客詳細

タブ:
- 概要
- 契約・担当
- 制作方針
- 投稿スケジュール
- 運用・消化
- 素材
- 投稿履歴
- 顧客確認履歴
- SNS・リンク
- ログイン情報
- 履歴

右上:
- 編集

## 顧客編集

編集対象:
- 基本情報
- 契約
- 主担当
- 副担当
- 投稿ルール
- 制作方針
- SNS URL
- Drive
- Canva
- 公式LINE
- ログインID
- パスワード保管先
- 通知・催促設定

投稿ルール変更時は既に着手済みタスクを勝手に動かさない。

## Wチェック待ち

一覧:
- 依頼日時
- 顧客
- 制作物
- 制作担当
- Wチェック担当
- 制作物リンク
- 投稿予定日
- 状態
- OK
- 修正依頼

画面上にチェック基準だけ表示:
誤字脱字 / テロップタイミング / 音量 / 動画の切れ / 見やすさ

## 投稿実績登録

投稿種別選択:
- リール
- フィード
- ストーリーズ

種別により入力フォーム切替。

### リール
- 投稿URL
- 完成動画アップロード
- Drive保存
- 元素材
- 投稿日
- 担当

### フィード
- 投稿URL
- Canva
- 元素材
- 投稿日
- 担当

### ストーリーズ
- Canva or ファイル
- 投稿日
- 担当
- 投稿URL任意

## 投稿カレンダー

- 自動生成予定を表示
- 投稿済みも表示
- 持越しを明確に表示
- 1件だけ日付変更
- 基本ルールは変更しない

## 通知 / 催促

独立画面として残す。

通知:
イベント通知。

催促:
- 素材待ち
- 顧客確認待ち
- 経過日数
- 最終催促日
- 催促済み記録

## スタッフ管理

- 姓
- 名
- 権限
- 個別ログイン状態
- 主担当顧客
- 副担当顧客
- 有効 / 無効

## スマホ

特に以下を片手操作しやすくする:
- 顧客ステータス変更
- Wチェック
- 素材確認
- 投稿実績登録
- 通知 / 催促
