# 1. 業務要件

## 目的

DOUSEN WORK は、SNS運用・投稿制作を中心とした社内業務管理システム。
担当者が開けば「今日何をすればいいか」「担当顧客がどの状態か」が即座に分かることを最優先とする。

## 主な利用者

- パート
- 社員
- 役員
- 社長
- 外注先（ログインなし、専用フォームのみ）

## 権限

### 社長 / 役員 / 社員
- 全情報閲覧可
- 全業務情報編集可

### パート
- 基本的に全顧客情報閲覧可
- 制作、Wチェック、顧客ステータス変更、投稿実績登録可
- 売上・料金のみ閲覧不可

## ログイン

スタッフごとの個別ログイン。
画面上は以下の入力を想定:
- 姓
- 名
- パスワード

内部的には Supabase Auth の `auth_user_id` と `staff.id` で識別する。
同姓同名を考慮し、氏名を主キーにしない。

## 顧客担当

- 基本は主担当1名
- 副担当を1名設定可能
- 将来的に複数担当へ拡張可能な設計にする
- 担当変更時、未完了タスクは新担当へ移す
- 過去実績の担当者は当時の担当者を保持

## 主な業務フロー

顧客登録
→ 投稿ルール登録
→ 制作タスク自動生成
→ 素材到着
→ 制作
→ Wチェック登録
→ Wチェック待ち
→ WチェックOK
→ 顧客確認
→ 顧客OK
→ 投稿
→ 投稿実績登録 + 完成動画格納
→ 完了

WチェックNG / 顧客修正依頼:
→ 制作中へ戻る
→ 修正
→ 再度Wチェック登録

## 顧客ステータス

担当者ダッシュボード上で直接変更可能。

候補:
- 順調
- 素材待ち
- 制作中
- Wチェック待ち
- 顧客確認待ち
- 投稿待ち
- 休止
- その他

顧客ステータスは「顧客全体の現在状態」。
制作タスクのステータスとは別管理。

## 制作タスクステータス

- 素材待ち
- 制作待ち
- 制作中
- Wチェック待ち
- 顧客確認待ち
- 投稿待ち
- 完了

## 素材

素材管理はシンプルにする。

保持したい情報:
- 顧客
- 内容
- 撮影日
- 受領日
- Google Drive ファイル/フォルダ参照
- 顧客フォームの投稿用途・投稿内容・編集指示等

以下は不要:
- 未使用 / 使用済み
- 使用回数
- 一度だけ / 複数回利用可 の分類

## Wチェック

制作担当が「Wチェック登録」する。

登録情報:
- 顧客
- 制作タスク
- 制作担当
- 制作物種別
- 動画の場合: Google Drive動画リンク
- フィード / ストーリーズの場合: Canvaリンク
- Wチェック担当（任意）
- 補足

Wチェック担当:
- 基本は全スタッフが対象
- 特定担当者を指定可能
- 指定なし = 誰でも対応可

チェック基準として画面に表示する:
- 誤字脱字
- テロップのタイミング
- 音量
- 動画の切れ
- 見やすさ

細かなチェックボックス管理は不要。

結果:
- OK → 顧客確認へ
- 修正依頼 → 制作中へ戻す

差し戻し回数の集計は不要。

## 顧客確認

公式LINE等で連絡。
LINE本文は保存不要。

状態:
- 返答待ち
- OK
- 修正依頼

保持:
- 確認依頼日
- 依頼したスタッフ
- 結果
- 返答日
- 修正内容メモ

修正依頼:
→ 制作中へ戻す

## 投稿実績

独立していた完成動画格納機能は廃止。
「投稿実績登録」に統合する。

### リール
必須想定:
- 顧客
- 投稿日
- 投稿担当
- 投稿タイトル/内容
- Instagram等の投稿URL
- 完成動画アップロード
- Google Drive保存先
- 元素材参照

登録時:
- 完成動画をGoogle Driveへ格納
- 投稿実績を保存
- 制作タスクを完了

### フィード
- 顧客
- 投稿日
- 投稿担当
- 投稿内容
- 投稿URL
- Canvaリンク
- 元素材参照

### ストーリーズ
- 顧客
- 投稿日
- 投稿担当
- Canvaリンクまたは画像/動画ファイル
- 投稿URLは任意
- 元素材参照

## 投稿完了の定義

「実際に投稿した」だけでは完了にしない。
「投稿実績登録まで完了」した時点で制作タスクを完了とする。

## 社内タスク

制作工程とは別の簡易タスク。

保持:
- 顧客紐づきあり/なし
- 担当者
- カテゴリ
- タイトル
- メモ
- 優先度
- 期限
- 状態
- 添付参照

例:
- 提案資料
- 議事録
- コンサル方針
- 社内マニュアル

## 外注

- 外注先はDOUSEN WORKへログインしない
- 案件単位で専用アップロードURLを発行
- 外注先は制作指示を確認し、完成物をアップロード
- 納品時に社内通知
