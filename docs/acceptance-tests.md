# 8. 最低限の受入テスト

1. パートでログイン → 顧客は見えるが料金・売上は見えない
2. 社員でログイン → 料金含め全情報が見える
3. 顧客登録 → リール4本/火曜 → 将来3か月分の制作タスクが生成
4. カレンダーで1件だけ日付変更 → 基本ルールは変わらない
5. 月末に1本未完了 → 翌月に持越し表示、前月実績は3/4のまま
6. 顧客ステータスを素材待ち → 開始日時が保存
7. Wチェック登録 → 待ち一覧へ出る
8. Wチェック修正 → 制作中へ戻る
9. WチェックOK → 顧客確認へ
10. 顧客修正 → 制作中へ戻る
11. 顧客確認14日 → 催促画面で赤
12. リール投稿実績登録 → Drive格納 + post_record + task完了
13. フィード投稿実績登録 → Canvaリンク + post_record + task完了
14. 担当変更 → 未完了だけ新担当へ、過去実績担当は維持
15. 外注専用URL → ログインなしで納品可能、社内通知発生
16. スマホでステータス変更 / Wチェック / 投稿実績登録が操作可能
